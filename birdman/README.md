# Birdman3D C++ — 鳥人間 機体設計シミュレーター 3D

`Birdman3Dβ.html`(Three.js版・約3100行)の **C++17 + SFML 2.6 + OpenGL + GLM** 移植+拡張。
物理コアはJS版互換の3DOFを基準に、揚力線理論(LLT)・ブレード要素運動量理論(BEMT)・
Re依存極曲線・Dryden乱流・たわみ連成6DOF・ねじり剛性由来のフラッター限界まで拡張済み。
解析はMIT Daedalus 88の公表値(総重量104kg・所要200-230W)と±10%で一致する(回帰テストで担保)。

## 起動

```
run.bat            # または build\birdman.exe をダブルクリック
```

### 機体自動最適化CLI

```
build\optimize.exe [--power 270] [--pilot 60] [--v0 7] [--sixdof]
                   [--gens 30] [--pop 64] [--seed 1] [--base 設計名] [--name 保存名]
```

オート操縦のヘッドレス飛行を並列評価し、飛距離最大の機体を進化的探索する。
妥当性フィルタ(SM/尾翼容積/桁強度/突風安全率)に加え、**手動・無入力での
プラットフォーム発進に高度余裕をもって成功する設計のみ**を許可(プレイアブル保証)。
`--sixdof` で6DOFモデルでの評価に切り替え。`--pareto` で「飛距離⇔桁安全率」の
パレートフロント(非劣解 最大5つ)も追加保存する。結果は `save/designs.json` に追記され、
ゲームの「保存・比較」から読込できる。

セーブ類はすべて **exeと同じ場所の `save/`**(best.json / badges.json / designs.json / birdman_ribs.svg)。

## ビルド(Windows / MSYS2 UCRT64)

```bash
# 1) 依存パッケージ
pacman -S mingw-w64-ucrt-x86_64-{gcc,cmake,ninja,glm,freetype,openal,libvorbis,libogg,flac}

# 2) SFML 2.6.2 をソースからビルド(MSYS2のsfmlは3.x系のため)
#    → deps/SFML-2.6.2 に展開済み。deps/sfml-install にインストール済み(audio有効)。
cd deps/SFML-2.6.2
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=OFF \
      -DSFML_BUILD_AUDIO=ON -DSFML_BUILD_NETWORK=OFF -DSFML_USE_SYSTEM_DEPS=ON \
      -DCMAKE_INSTALL_PREFIX=../sfml-install
cmake --build build --target install

# 3) 本体
cd ../..
cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release \
      -DSFML_STATIC_LIBRARIES=TRUE -DSFML_DIR="$PWD/deps/sfml-install/lib/cmake/SFML"
cmake --build build

# 4) 物理コアテスト(3DOF/6DOF回帰含む)
./build/physics_test.exe
```

## 操作

| 操作 | キー |
|---|---|
| エレベーター(引起/押え) | ↑↓ または W/S |
| 地上ブレーキ(滑走中) | S / ↓ (押している間。キャッチャー相当) |
| エルロン(放すと水平復帰) | ←→ または Q/E |
| ラダー(地上では前輪/尾輪ステア) | A / D |
| 出力 ±20W(お遊び機はスロットル) | R / F (PageUp/Downも可) |
| 発進 / 中止 | Space、または画面下部のボタン |
| ミッション挑戦 1〜6 | F1〜F6 (設計モード) |
| 大会に出場 | F7 (設計モード・予算/ロック条件を満たす時) |
| リプレイ 開始/終了 | F8 (飛行モード)、または下部バーのボタン |
| デブリーフ 開閉 | F9 (飛行モード)、または下部バーのボタン |
| パッド操作 | スティックX=エルロン Y=エレベーター ひねり=ラダー (接続時自動有効) |
| カメラ回転 / ズーム / 平行移動 | ドラッグ / ホイール / 右ドラッグ |

- **設計モード**: 左パネルで機体設計(テンプレート+スライダー)。メトリクスと3D機体がリアルタイム更新。
  下部ツールバー: **荷重・たわみ**(Schrenk分布/曲げ/たわみ3D表示) / **ポーラー**(所要パワー・L/D・抗力内訳) /
  **保存・比較**(designs.jsonの読込・削除・メトリクス比較) / **リブ型紙**(mm実寸SVG出力)
- **テストフライト**: プラットフォーム発進 / 滑走路離陸。左上「設定」からシミュ設定・風/天候(天気ガチャ・夏の琵琶湖モード)。
  - **プラットフォームはデッキ滑走式**: 後端(高10.6m)から傾斜3.5°・10mの助走路を台車で加速して前縁(高10.0m)から飛び出す。
    発進速度スライダー=助走開始速度。Sキーで発進中止(低速のうちなら前縁までに停止できる)
  - **滑走路はプッシャー発進**: 人力補助の初速(スライダー)から滑走。引き起こしはVs到達で可能。
    再着陸→ブレーキ停止で「着陸成功」終了。タッチ&ゴーも可
- **お遊びモード: 小型プロペラ機**(設定→飛行シミュ): 超軽量動力機(35kWエンジン・失速14m/s)で滑走路から自由飛行。
  出力スライダーがスロットルになり、コース逸脱打切りなし。バッジ・記録・大会の対象外
- **天候「富士川滑空場日和」**: 天気ガチャに10%で登場。川筋の谷風(向かい風基調・振れ大)+最強サーマル
- **パイロット視点 + HUD計器**: 人工水平儀・速度/高度テープ・荷重/出力ゲージ。
- **翼たわみ**: 荷重nに連動して翼が実たわみ曲線(EI積分)でしなる。駐機中は自重たれ。
- **サウンド**: 風切り(対気速度連動)・プロペラ(rpm連動)・着水/破壊/接地。全て手続き生成でアセット不要。
  設定→飛行シミュでON/OFF切替。
- **キャリア大会のライバル機**: 大会には3チームのライバルが同じ天候で同時発進(オート操縦)。
  画面左に順位がライブ表示され、最終順位で優勝ボーナス(+80万円・評判+1)。
  大会中は体力モデル強制・オート/ホールド/天候操作・CLmax変更など**チート設定がロック**され、
  発進速度は人力押し出しの上限7.5m/sに制限。中止した場合はその地点までが公式記録。
- **パイロン周回コース**(プラットフォーム発進時): 北パイロン(11km先)を回ってPFへ戻ると
  周回タイム計測(片道11km・周回22km)。HUD左上に次目標との距離、GPSマップに目標リング表示。
  通過・周回でバッジ獲得。
- **琵琶湖地形**: 湖岸ポリゴンによる実形状の湖面と周囲の陸地・湖岸沿いの山並み(西=比良山地は高い)・竹生島。
  着水/墜落の水面・陸面判定も湖形状に従う。
- **地形風**(設定→風・突風でON/OFF): 西岸の比良おろし(下降流+東向き、天候「比良おろし」で激化)、
  東岸の岸サーマル(陸上対流の上昇流帯)。コース中心線上はゼロでJS互換を維持。
- **リプレイカメラ**(飛行終了後): 直前フライトをシネマティック再生(オービット/真横/引き俯瞰を8秒毎に切替)。
  全体を最長60秒に自動スケール、ループ再生、進捗バー付き。
- **フライトデブリーフ**(飛行終了後): 高度・速度の全時系列チャート(最高点マーク・失速域表示)+
  飛行時間/最高高度/最高速度/最大荷重/失速域滞在/平均速度の統計。
- **風の可視化**: 実際の風場(基本風+地形風+サーマル)で移流する粒子。上昇流=緑、下降流=橙、水平風=白。
  リアルサーマルON時はアクティブな上昇帯の上空に積雲マーカー。設定→風・突風でON/OFF。
- **地面効果の可視化**: 機体の影(低高度ほど濃い)と、地面効果域(h<3.5m)で水面を走るさざ波リング。
- **チャレンジミッション**(設計→ミッション): 朝凪1km/ルーキー200W/比良おろし/午後の魔物/
  サーマルライダー/北パイロンTA の6種。挑戦で天候・条件が固定され、達成でバッジ。終了後は設定復元。
- **キャリアモード**(設計→キャリア): 年次大会。機体の製作コスト(桁/リブ/フィルム/ペラ等の内訳)が
  予算内なら出場可。天候は当日ガチャ・手動一発勝負。記録に応じて賞金と評判、評判で高級パーツ解禁
  (高弾性率CFRP/CFRPペラ/エース/翼幅32m超)。`save/career.json` に保存。
- **体力モデル(手動)**(設定→飛行シミュ): オート専用だったCP+W'balを手動出力にも適用。
  スライダーで無理を要求するとW'が枯渇し持続出力まで強制低下。
- **フラッター・疲労**: VNEの88%超で翼が振動し疲労が蓄積(画面に警告)、蓄積1.0で疲労破断。
  高荷重(0.8×限界超)の繰返しでも蓄積。翼の震えが視覚的な前兆警告になる。
  **VNE自体は桁のねじり剛性GJから計算**(ねじり発散の~50%)。細い桁・低弾性率はフラッター限界が下がる。
- **リアルサーマル**(設定→風・突風): 湧いて消える円形サーマルセル(7〜11分周期・決定的)。
  OFFでJS互換の固定関数サーマル。
- ベスト記録・バッジは `save/best.json` / `save/badges.json` に保存(ゴースト機で自己ベストと競走)。
- フォントは NotoSansJP を同梱(assets/fonts/、OFLライセンス)。システムフォント非依存で配布可能。

## 物理モデル(設定→飛行シミュで切替)

共通の空力基盤(両モデルで使用):
- **揚力線理論(LLT)**: 平面形・ねじり下げからスパン効率eと3D失速CL・失速開始位置を解く
- **BEMTプロペラ**: 直径・ピッチ・ブレード数から推力/回転数を物理計算(静止推力〜風車域まで)
- **Re依存極曲線**: 翼型ごとのXFOIL系テーブルで低Re域の「Reの壁」を再現
- **Dryden型乱流**: 高度・風速依存の相関時間を持つ連続乱流
- **暑熱・体力**: 気温24℃超でCP低下(0.6%/℃)。「朝凪のうちに飛ぶ」が戦略になる

- **標準(JS互換)**: JS版と同一の3自由度+バンク。CL式に「1g維持+沈下率減衰」の
  完璧なパイロットが内包されており、手放しで安定飛行する。エルロン解放で水平復帰。
- **6DOF(実験)**: ピッチ/ロール/ヨーの回転動力学を解く(減衰項は半陰的積分で無条件安定)。
  静安定余裕SM(Cmα)・尾翼容積(Cmq/Cnβ)・上反角効果(Clβ、**たわみ連成**で荷重n依存)・
  アドバースヨー・**翼端失速のロール崩れ(LLT連動)**が動的挙動として現れる。
  暗黙パイロット(沈下抑制・ウィングレベラー・ラダー協調)は入力に応じてフェードアウト。
  - 失速は**マッシュ(緩失速)+機首下げブレーク**として発現し回復性がある
    (急峻なCL崩壊は揚力減→経路角低下→迎角増の正帰還で非物理的な深失速ロックを
    起こすため採用しない)
  - 無入力時は沈下率を打ち消す**暗黙のパイロット**(微小エレベーター)が働き、
    JS 3DOFと同じ操作感で手放し飛行できる。入力するほどフェードアウト
  - 発進直後は現在対気速度に釣り合う迎角でトリム開始(発進ダイブの再現)
  - 失速速度超の機体は発進ダイブで着水する(**3DOFでも同様**)。着水時に
    発進速度/失速速度のヒントを表示

## 構成

```
src/
├── core/      Aircraft(解析) / Physics(stepSim・stepSim6・aeroPack) / Weather / DesignIO
├── render/    Renderer3D(OpenGL: 湖・発進台・機体・たわみメッシュ・エフェクト) / Camera / HUD(+汎用チャート)

tests/physics_test.cpp   物理コア単体テスト(3DOF/6DOF/発進マトリクス回帰)
```

## 移植時の改良点(プロンプトからの意図的な差分)

1. **物理dt = 0.02秒**: プロンプトは「0.05秒(JSと同じ)」と記載しているが、実際のJS `simTick` は
   `stepSim(L, 0.02)` を使用。リファレンス実体に合わせ0.02秒とした。
2. **物理コアはdouble精度**: JSのNumberはdoubleのため、float指定より数値一致性が高い。
3. **フェアリングのCD0低減(-0.0012)を飛行物理にも反映**: JS版では `analyze()` のみに入っていて
   飛行シミュの `aeroConsts()` には抜けていた(=フェアリングが飛行に無効)バグを修正。
4. **UIウィジェットは永続オブジェクト**: JSの「ボタン毎フレームDOM再生成」バグの教訓どおり、
   `Button`/`Slider` は生成後保持し状態のみ更新。
5. サーマル係数(0.25)・BIWA_WEATHERのtherm値(humid=0.6)は修正済みの値(HTMLに反映済み)を使用。
6. 最適化の30km打切り到達時は「残時間×平均速度」で外挿した仮想距離で順位付け。
